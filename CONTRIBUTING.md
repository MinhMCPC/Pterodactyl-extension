# Contributing to Pterodactyl SFTP

Thank you for your interest in contributing to the Pterodactyl SFTP extension!

## Reporting Issues

If you encounter any bugs or have feature requests, please open an issue on our GitHub repository. Include as much detail as possible:

-   Steps to reproduce.
-   Expected behavior vs. actual behavior.
-   Screenshots or logs (if applicable).

## Development Setup

1.  Clone the repository.
2.  Run `npm install` to install dependencies.
3.  Open in VS Code.
4.  Press `F5` to start debugging.

## Pull Requests

1.  Fork the repository.
2.  Create a new branch for your feature or fix.
3.  Commit your changes with clear messages.
4.  Push to your fork and submit a Pull Request.
